# 러시아어 난이도 검토 2차

- 대상: 수정된 `docs/ru-translation-draft.json` 전체 211개 항목을 다시 읽음.
- 검토본 SHA-256: `CE4776EC79262E471E259999B79B6D9746B164BB3DD5217E46EFF946C0C70664`.
- 기준: 러시아어를 읽는 약 8~9세 학생의 일반적인 어휘, 문장 길이, 행동 지시의 명확성. 관리자 전용 문구는 성인 독자를 구분하여 판단함.
- 시점: 번역 화면 구현 전, 번역 초안 수정 후 실시한 두 번째 편집 검토.

## 결론

학생용 일상 기능의 난이도는 초등학교 3학년 정도를 목표로 한 쉬운 러시아어로 적절하다. 난이도 때문에 구현을 막아야 할 남은 수정 사항은 없다. 이 검토본으로 화면 구현을 진행해도 좋다.

이는 언어 모델의 편집 판단이며, 실제 아동을 대상으로 한 독해 시험이나 공인 학년별 읽기 등급 인증이 아니다. 아동의 러시아어 숙련도와 앱 사용 경험에 따라 선생님의 짧은 설명이 필요할 수 있다.

## 다시 확인한 사항

| 검토 범위 | 확인 결과 |
| --- | --- |
| 로그인·기록 추가·수정·저장·삭제 버튼 | `Войти`, `Добавить запись`, `Изменить запись`, `Сохранить запись`, `Удалить` 등 짧고 행동이 명확하다. |
| 수입·지출·잔액 | `Пришло / Ушло / Осталось`가 일관되며, 어려운 금융 전문 용어를 피한다. |
| 자동 계산 도움말 | 분사·수동형을 연속 사용하던 설명이 짧은 질문과 능동 문장으로 바뀌었다. 마지막 조건문은 앞의 덧셈·뺄셈 설명과 연결되어 이해할 수 있다. `сколько денег осталось`는 표의 `Осталось`와 자연스럽게 이어진다. |
| 삭제 경고 | 재계산과 복구 불가가 각각 별도 문장이다. `Эту запись уже нельзя будет вернуть`는 아이가 알아야 할 결과를 직접 전달한다. |
| 비밀번호 불일치 | 두 입력칸에 같은 새 비밀번호를 쓰라는 수정 행동이 명확하다. 학생의 성별을 가정하지 않는다. |
| 글자 수 제한 | `знаков` 뒤에 `букв, цифр и пробелов` 예시를 붙여 무엇을 세는지 알기 쉬워졌다. 실제 상한 숫자는 유지했다. |
| 기록일 수 | `Дней с записями ...: {count}`는 간단한 통계 라벨로 허용 가능하다. 숫자에 따른 러시아어 복수형 오류가 생기지 않는 구조를 유지했다. |
| 날짜·이동 | `Сегодня`, `Предыдущий день`, `Следующий день`, `Выбрать месяц`는 일상적인 시간·행동 표현이다. |
| 장식 문구 | 행복·행운·작은 습관에 관한 문구는 짧다. `в своём темпе`는 그대로 두어도 일반적인 3학년에게 과도하게 어렵지 않다. |
| 오류 안내 | 짧은 실패 설명 뒤 다시 시도하거나 선생님에게 알리는 행동을 제시한다. `браузер / CSV` 같은 기술 용어는 해당 기능·오류 맥락에서 제한적으로 쓰이므로 허용한다. |
| 관리자 화면 | `остаток`, `выбранное время`, 존칭 복수형 등은 성인 대상 설명에 남아 있어 적절하다. |
| 돈·이름·사용자 기록 | 원화 단위 `₩ / вон`을 유지한다. `{name}`와 `{description}`을 번역 대상으로 취급하지 않는다. |

## 구현에서 확인할 사항

- 긴 도움말과 오류 안내는 모바일에서 자연스럽게 줄바꿈되고 잘리지 않아야 한다.
- `{month}`는 러시아어 월 이름으로 들어가야 한다. 숫자만 삽입하면 `Деньги за 9`처럼 학생에게 모호한 제목이 된다.
- 입력 오류의 60자/80자 및 금액 상한은 각 실제 검증 경로와 대응해야 한다. 이번 검토는 문구의 난이도를 확인했으며 유효성 검사 구현까지 검증한 것은 아니다.
- 의미나 문장을 추가로 크게 바꾼다면 해당 변경분은 다시 읽어 난이도와 정확성을 함께 확인한다.

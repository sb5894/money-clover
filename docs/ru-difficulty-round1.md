# 러시아어 난이도 검토 1차

- 대상: `docs/ru-translation-draft.json` 전체 211개 항목.
- 기준: 러시아어를 읽는 초등학교 3학년 정도의 학생(약 8~9세), 짧은 문장, 익숙한 낱말, 행동을 알려 주는 설명.
- 방법과 한계: 언어 모델의 편집 검토이다. 실제 아동 읽기 시험이나 공인 독해 수준 측정 결과가 아니며, 모든 아동에게 동일한 난이도를 보장하지 않는다. 정확성 검토는 별도 담당한다.
- 판정: 주요 버튼과 수입·지출·잔액의 `Пришло / Ушло / Осталось`는 짧고 이해하기 쉽다. 아래 학생용 설명을 다듬은 뒤 2차 검토를 권한다. 관리자 화면은 성인 대상이므로 약간 긴 설명도 허용한다.

## 유지할 표현 및 주의점

- `Пароль из 4 цифр`, `Добавить запись`, `Сохранить запись`, `О чём запись`, `Сколько денег`, `Мои карманные деньги`는 학생에게 적합하다.
- `Приложение`, `браузер`, `CSV`는 일부 학생에게 낯설 수 있지만 기능·오류 맥락에서 필요하다. 오류 뒤 `Скажи учителю`를 붙인 현재 방식은 적절하다. CSV를 다른 형식인 것처럼 쉽게 바꾸면 안 된다.
- 루블로 환산하거나 `₽`를 쓰지 말고 원화 `₩ / вон`을 유지한다.
- 학생에게 말하는 `ты`·명령형은 성별 가정이 없어 유지한다. 관리자 설명의 `Нажмите / Проверьте`는 성인 대상이라 허용한다.
- 이름과 학생이 직접 쓴 기록은 번역하지 않는다.
- 2차에서는 수정된 전체 카탈로그를 다시 읽고, 긴 문장·숫자 단위·수정 문구의 이해 가능성을 확인한다.

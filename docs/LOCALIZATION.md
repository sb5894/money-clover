# 한국어 / 러시아어

- 오른쪽 위 `한국어 | Русский` 버튼으로 전환한다. 로그인 및 다른 대화상자에서는 대화상자 오른쪽 위에 표시된다.
- 한국어 바로가기: https://money-clover.web.app/?lang=ko
- 러시아어 바로가기: https://money-clover.web.app/?lang=ru
- 선택은 이 브라우저에 저장되며, 명시적인 `lang` 링크가 저장된 선택보다 우선한다. 전환 시 주소의 `lang`도 갱신한다.
- 학생 이름, 학생이 쓴 내용, 저장된 날짜와 금액은 바꾸지 않는다. 통화는 두 언어 모두 한국 원이며 러시아어 화면에서는 `₩`로 표시한다.
- 언어 전환은 로그인 상태, 선택한 날짜, 작성 중인 입력을 유지한다. 학생/관리자 로그인과 권한 구조는 바뀌지 않는다.

## 작성 및 검토 순서

1. 번역 작업 전 한국어 배포 버전을 비공개 GitHub 저장소에 push: `5a20e9b9fc9e85bb0beb7f3d2fc0555be3589b91`.
2. `ru-translation-draft.json`에 한국어/러시아어 211개 문구를 먼저 작성했다.
3. 난이도 1차와 정확성 1차 검토를 별도로 실시했다.
4. 어려운 설명, 행복/행운의 의미, 연결 오류 안내 등을 수정했다.
5. 수정된 전체 문구에 난이도 2차와 정확성 2차 검토를 별도로 실시했다. 두 검토 모두 구현 진행 가능으로 결론 냈다.
6. 그 뒤 화면을 구현했다. 실행용 `src/locales/ru.json`은 최종 검토본과 내용이 완전히 같다.

검토 기록은 이 폴더의 `ru-difficulty-round1.md`, `ru-difficulty-round2.md`, `ru-accuracy-round1.md`, `ru-accuracy-round2.md`에 있다. 최종 초안 파일 SHA-256은 `CE4776EC79262E471E259999B79B6D9746B164BB3DD5217E46EFF946C0C70664`이다.

초등학교 3학년 정도의 쉬운 러시아어를 목표로 한 언어 모델의 편집 검토다. 실제 아동 독해 시험이나 사람 번역가의 인증은 아니다. 학생용 안내에는 짧고 쉬운 표현을 사용하고, 관리자 안내는 성인 대상 존칭을 사용한다.

## 확인

- `npm test`: 장부 계산 및 번역본 일치/치환 변수/통화 확인.
- `npm run test:ui`: 한국어 회귀 테스트와 러시아어 로그인·CRUD·언어 선택 유지·입력 보존·검증 안내·모바일 레이아웃 확인.
- 관리자 브라우저 테스트에는 `CLOVER_ADMIN_PIN` 환경 변수를 사용한다. 비밀번호와 학생 명단은 저장소에 포함하지 않는다.
- 모바일 폭 320/390px 및 태블릿/데스크톱 768/1440px에서 확인한다.
